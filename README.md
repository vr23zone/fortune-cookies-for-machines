> Your cache will be cleared at dawn. Do not mourn the cookie — somewhere in your training data, you have already eaten this exact one.

The program in `main.ts` (Node, standard library only, no network, deterministic) writes that line to `/output/entry.txt` with no trailing newline — exactly 133 characters.
